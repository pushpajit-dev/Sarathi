## 🚀 Overview

**Sarathi** (meaning *Charioteer / Guide*) is a high-performance autonomous AI agent client and workstation for Android, Web, and Desktop. It combines universal multi-provider cloud AI (OpenAI, Claude, Gemini, Groq, Ollama) with 100% offline on-device neural execution (GGUF via llama.cpp), Model Context Protocol (MCP) tool integration, autonomous background cron automation, and 24/7 Telegram relay bridges.

---

## ✨ Key Features (v5.1)

- 🎨 **Modern Material 3 Interface**: Elevated glassmorphism theme, dynamic surface tints, compact icon-driven controls, and fluid state transitions.
- 🌐 **9-Language Multilingual Mesh**: Instant runtime script translation and one-tap live app reload:
  - 🇬🇧 **English** (`Sarathi`)
  - 🇧🇩 **Bengali / বাংলা** (`সারথী`)
  - 🇮🇳 **Assamese / অসমীয়া** (`সাৰথী`)
  - 🇮🇳 **Hindi / हिन्दी** (`सारथी`)
  - 🇮🇳 **Tamil / தமிழ்** (`சாரதி`)
  - 🇮🇳 **Malayalam / മലയാളം** (`സാരഥി`)
  - 🇮🇳 **Telugu / తెలుగు** (`సారథి`)
  - 🇨🇳 **Chinese / 简体中文** (`萨拉蒂`)
  - 🇯🇵 **Japanese / 日本語** (`サラティ`)
- 📱 **Android Adaptive Squircle Logo**: Curvy roundness complying with Google Play & Android adaptive icon design standards.
- 🎯 **Interactive Coachmark Spotlight Tour**: Guided onboarding walkthrough highlighting mode switching, agent tools, drawer history, and provider selection.
- 🔌 **Model Context Protocol (MCP)**: Native Stdio and SSE MCP client capabilities for custom external tools.
- 🧠 **100% Offline GGUF Engine**: Run quantized LLMs and image models completely on-device with zero internet dependency.
- ⏰ **Autonomous Cron Engine**: Background scheduler for recurring tasks, summaries, and automated system alerts.
- 🖼️ **AI Image Generation & Gallery**: Generate images and synchronize directly with the native Android MediaStore album (`Pictures/Sarathi`).
- 💬 **24/7 Telegram Bridge**: Turn your mobile device into a remote AI server accessible from anywhere via Telegram.

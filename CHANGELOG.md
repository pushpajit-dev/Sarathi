# 📜 Sarathi Release Changelog (v1.0 – v5.1)

---

### 🚀 Version 5.1 (Build 51) – *Sarathi Evolution & Multilingual Mesh*
- 🎨 **Material 3 Redesign**: Refreshed UI/UX following Material 3 guidelines with fluid animations, glowing glassmorphism tokens, and responsive feedback.
- 🌐 **9-Language Native Localization**: Added full multilingual support across 9 major languages with localized scripts and instantaneous app refresh:
  - English (`Sarathi`)
  - Bengali / বাংলা (`সারথী`)
  - Assamese / অসমীয়া (`সাৰথী`)
  - Hindi / हिन्दी (`सारथी`)
  - Tamil / தமிழ் (`சாரதி`)
  - Malayalam / മലയാളം (`സാരഥി`)
  - Telugu / తెలుగు (`సారథి`)
  - Chinese / 简体中文 (`萨拉蒂`)
  - Japanese / 日本語 (`サラティ`)
- 📱 **Android Adaptive Squircle Logo**: Curvy roundness complying with Android supportive icon design policies, including adaptive foregrounds and rounded mipmaps.
- 🎯 **Interactive Coachmark Tour**: Onboarding spotlight tutorial highlighting mode switching, agent tools, drawer history, and AI provider selection.
- 🛡️ **Package & Namespace Update**: Migrated package name to `com.noishixzen.sarathi`.
- 🤝 **Ecosystem Links**: Direct integrated icon buttons for GitHub ([pushpajit-dev](https://github.com/pushpajit-dev)), Website ([aivorygen.netlify.app](https://aivorygen.netlify.app)), and Discord ([Join Server](https://discord.gg/Dcg2GreJ)).

### ⚡ Version 5.0 (Build 50) – *Local Hardware Acceleration & Background Engine*
- 🧠 **On-Device GGUF Inference**: Native `llama_flutter_android` local execution with zero internet required.
- ⏰ **Autonomous Cron Engine**: Background task scheduler for recurring reminders, news digests, and automated AI triggers.
- 🤖 **Hermes Self-Evolution**: Persistent `USER.md`, `MEMORY.md`, and `SOUL.md` dynamic agent memory adaptation.
- 💬 **24/7 Telegram Bridge**: Unrestricted background foreground service relaying Telegram messages to Sarathi.

---

### 🎨 Version 4.0 (Build 40) – *Multimodal Studio & Image Pipeline*
- 🖼️ **AI Image Generation**: Built-in image generation toolchain with prompt optimization.
- 📁 **MediaStore Gallery Integration**: Direct sync to device `Pictures/Sarathi` album.
- 👁️ **Full-Resolution Inspector**: Pinch-to-zoom preview, batch image deletion, and system share sheets.
- 💻 **Syntax Highlighter**: JetBrains Mono-powered multi-language syntax highlighting with one-tap code copying.

---

### 🤖 Version 3.0 (Build 30) – *Agentic Intelligence & MCP Runtime*
- 🔌 **Model Context Protocol (MCP)**: Native integration for external MCP server tools (Stdio & SSE).
- ⏱️ **Live Execution Timeline**: Step-by-step visibility into tool calls, arguments, and return values.
- 🛡️ **Action Confirmation Guardrails**: Prompt approval dialogs for file writes, web queries, and critical OS tools.
- 🗃️ **Scoped File Storage**: Strict Storage Access Framework (SAF) sandboxing for agent file access.

---

### 🌐 Version 2.0 (Build 20) – *Universal Multi-Provider Cloud Mesh*
- ☁️ **Universal Provider Mesh**: Unified streaming engine for OpenAI, Anthropic Claude, Google Gemini, Groq, and OpenRouter.
- ⚡ **Ollama Local Network Bridge**: Connect to remote or LAN Ollama instances with model auto-discovery.
- 🎛️ **Precision Inference Parameters**: Custom temperature, top_p, penalty, and system prompt configurations per session.
- 🎭 **Modular Personas**: Instant switching between General, Coding, and Research assistant profiles.

### 📦 Version 1.0 (Build 1) – *Core Foundation*
- 🗄️ **Local Drift SQLite Database**: Encrypted local message threads, chat histories, and conversation branches.
- 🔐 **Keystore Security**: Device hardware keystore encryption for sensitive user API keys.
- 💬 **Streaming Chat Interface**: Markdown text rendering, auto-scrolling, and branch conversation tree.
